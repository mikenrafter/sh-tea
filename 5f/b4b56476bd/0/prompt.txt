## Key finding during RED that shaped the test design

Deterministically reaching `ActivatedAgentic`/`ActivatedInteractive` (not `--tea`/`TEA_FORCE`) inside this bash harness required defeating two suppressors that force/env activation bypass but auto-detect does not:
- `parent_is_running_script()` — the harness itself runs as `bash tests/functional.sh` (a script file), which trips this check for any command invoked directly. Routing the invocation through `timeout N ...` works because `timeout` is a genuine non-shell parent process (confirmed empirically via `tea which --piped`; a `bash -c '...'` wrapper does *not* work here because bash's own exec-optimization collapses it back into the outer script's PID).
- `systemd_suppresses_activation()` — this sandboxed environment always has `INVOCATION_ID` set with stderr not a TTY; bypassed with `TEA_INTERACTIVE=1`.

So the recipe used is: `timeout 10 env -u TEA_OFF TEA_AGENT=1 TEA_USER_PIPE=1 TEA_INTERACTIVE=1 ...`.
